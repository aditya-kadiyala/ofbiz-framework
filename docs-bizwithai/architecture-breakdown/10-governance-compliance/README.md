# 10. Governance & Compliance

## Overview

This section documents OFBiz governance and compliance capabilities: audit trails, data privacy (GDPR), access control (RBAC/ABAC), and regulatory compliance. Essential for organizations with compliance requirements.

## Contents

1. **[Audit Trail Architecture](audit-trail-architecture.md)** - Audit logging, data retention, audit log patterns
2. **[Data Privacy & GDPR](data-privacy-gdpr.md)** - PII handling, data classification, GDPR compliance capabilities
3. **[Access Control (RBAC/ABAC)](access-control-rbac-abac.md)** - Role-based and attribute-based access control, segregation of duties
4. **[Regulatory Compliance](regulatory-compliance.md)** - Financial controls, regulatory reporting, compliance frameworks

## Key Concepts

- **Audit Trail**: Comprehensive logging of all data changes
- **Data Privacy**: PII identification, encryption, and access controls
- **RBAC**: Role-based access control with fine-grained permissions
- **ABAC**: Attribute-based access control for complex scenarios
- **Segregation of Duties**: Prevent conflicts of interest
- **Regulatory Compliance**: SOX, GDPR, and other compliance frameworks

## Who Should Read This Section?

- **Compliance Officers** assessing compliance capabilities
- **Security Architects** implementing access controls
- **Auditors** understanding audit trail capabilities
- **Data Privacy Officers** ensuring GDPR compliance
- **Risk Managers** evaluating controls
